# Telangana-PDS-Analytics
Telangana PDS Analytics: Multi-Dimensional Shop Performance Clustering and Anomaly Profiling using PCA, K-Means, DBSCAN and Streamlit. 

## Multi-Dimensional Shop Performance Clustering and Anomaly Profiling 
### Technologies Used
- Python
- Pandas
- Scikit-Learn
- PCA
- K-Means
- DBSCAN
- Streamlit
- Folium
 
### Project Objective
Analyze Telangana Fair Price Shop performance using clustering and anomaly detection techniques.
 
### Features
- Exploratory Data Analysis
- PCA Visualization
- K-Means Clustering
- DBSCAN Outlier Detection
- Cluster Profiling
- Interactive Dashboard
